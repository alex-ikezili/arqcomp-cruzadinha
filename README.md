# Cruzadinha de Arquitetura Computacional

Jogo de cruzadinha feito com **HTML, CSS e JavaScript puros** para revisar conceitos de Arquitetura Computacional.

## Como jogar

1. Leia as pistas em **Horizontais** e **Verticais**.
2. Digite as letras diretamente nas casas do tabuleiro.
3. Clique em **Conferir** para validar as respostas.
4. Veja o contador de acertos (ex.: `8 de 12 palavras`).
5. Clique em **Reiniciar** para limpar o tabuleiro e começar de novo.

## Palavras usadas e pistas

### Horizontais

1. **FLASH** — Memória não volátil utilizada em cartões e unidades USB.
2. **CPU** — Componente que executa instruções e coordena operações do computador.
3. **ROM** — Memória que conserva informações mesmo sem alimentação elétrica.
4. **DATABUS** — Conjunto de linhas responsável pelo transporte de informações entre componentes.
5. **MEMORIADEMASSA** — Meio utilizado para guardar arquivos e programas de forma persistente.
6. **ADDRESSBUS** — Conjunto de linhas que indica a localização dos dados na memória.

### Verticais

1. **DUALCORE** — Processador que possui dois núcleos de processamento.
2. **REGISTRADORES** — Pequenas áreas internas que armazenam dados durante o processamento.
3. **ULA** — Parte que realiza cálculos e operações lógicas.
4. **EEPROM** — Memória não volátil que pode ser apagada e reprogramada eletricamente.
5. **CACHE** — Memória rápida que guarda dados frequentemente acessados pelo processador.
6. **RAM** — Memória volátil usada para guardar dados enquanto o sistema está ligado.
